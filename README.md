# cybersec-journey

Saya adalah mahasiswa jurusan Informatika di Universitas Sultan Ageng Tirtayasa. Repositori ini akan menjadi tempat dokumentasi dalam pembelajaran cybersecurity di laman Tirtayasa Information Security Society (TISS). Saya memiliki motivasi untuk mulai belajar cybersecurity di TISS sebagai langkah awal yang paling mudah dijangkau, karena dari komunitas ini juga saya bisa berdiskusi dengan sesama teman yang juga menjalani academy TISS.Target rank yang ingin saya raih adalah rank 5-Sentinel.
